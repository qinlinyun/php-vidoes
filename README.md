# 影视系统

一个现代化的 PHP 影视管理系统，支持用户管理、分组管理、域名管理、站内通知、意见反馈与视频播放。

## 功能特性

### 用户管理
- 用户注册（用户名、邮箱、密码）
- 用户登录/登出
- 注册用户默认属于"注册用户组"

### 管理员功能
- **用户管理**：
  - 封禁用户
  - 删除用户
  - 自定义时间封禁用户
  - 冻结用户
  - 重置用户密码
  - 更改用户分组

- **用户分组管理**：
  - 新增分组
  - 删除分组

- **域名管理**：
  - 添加多个视频域名
  - 给用户组分配单独的域名
  - 管理员可在播放页面切换所有域名

- **视频管理**：
  - 添加视频（标题、描述、封面）
  - 添加视频集数（视频名称、视频链接）
  - 编辑视频和集数
  - 删除视频和集数
  - 自动去除视频链接中的域名和协议

- **站内通知**：
  - 发布全员通知
  - 发布指定用户通知
  - 管理端可删除通知

- **意见反馈**：
  - 用户提交反馈（支持上传图片，jpg/jpeg/png ≤10MB）
  - 管理端回复用户反馈
  - 双端可查看回复历史

### 播放功能
- 自动拼接域名（用户组分配的域名 + 已去除域名的视频链接）
- 支持多线路切换
- 如果用户组有多个域名，显示"当前线路XXX"并可切换
- 响应式设计，支持PC和手机

### 用户中心功能
- 站内通知列表（含未读/已读）
- 意见反馈（查看/回复/图片）
- 登录后未读弹窗提醒（通知 + 反馈回复）

## 安装说明

### 环境要求
- PHP 7.4 或更高版本
- MySQL 5.7 或更高版本
- Apache/Nginx Web服务器
- PDO MySQL扩展

### 安装步骤

1. **上传文件**
   将所有文件上传到Web服务器目录

2. **访问安装页面**
   在浏览器中访问：`http://your-domain/install.php`

3. **配置数据库**
   - 填写数据库主机（通常是 localhost）
   - 填写数据库名称（将自动创建）
   - 填写数据库用户名
   - 填写数据库密码

4. **完成安装**
   - 点击"开始安装"按钮
   - 系统将自动创建数据库和表结构
   - 创建默认管理员账户：
     - 用户名：`admin`
     - 密码：`admin123`

5. **开始使用**
   - 安装完成后，访问首页登录
   - 使用管理员账户登录后可以开始管理

### 已安装系统更新
- 如果你是已安装系统：访问 `update_db.php` 自动补齐新表结构
- 数据库表添加与回滚：`install_schema.php`

## 使用说明

### 添加视频

1. 以管理员身份登录
2. 进入"视频管理"
3. 填写视频信息（标题、描述、封面URL）
4. 点击"添加视频"
5. 在视频列表中找到刚添加的视频，点击"管理集数"
6. 添加集数：填写集数名称和视频链接
   - 视频链接会自动去除域名和协议
   - 例如：输入 `https://example.com/video.mp4` 会自动保存为 `/video.mp4`

### 配置域名

1. 进入"域名管理"
2. 添加视频域名（可以添加多个）
3. 在"分配域名给用户组"中，为每个用户组选择可用的域名
4. 用户播放视频时会自动使用其用户组分配的域名

### 用户管理

1. 进入"用户管理"
2. 可以对用户进行以下操作：
   - **封禁**：永久封禁用户
   - **定时封禁**：设置封禁到期时间
   - **删除**：删除用户账户
   - **冻结**：冻结用户账户（可解冻）
   - **重置密码**：重置用户密码
   - **更改分组**：更改用户所属分组

### 站内通知
1. 管理员进入“站内通知管理”发布全员或指定用户通知
2. 用户端在“站内通知”查看所有可见通知
3. 用户访问通知页面后自动标记已读

### 意见反馈
1. 用户在“意见反馈”提交内容（可附图，jpg/jpeg/png ≤10MB）
2. 管理员在“意见反馈管理”回复
3. 用户端可继续回复并查看历史

## 安全说明

- 默认管理员密码为 `admin123`，请登录后立即修改
- 建议在生产环境中修改默认管理员用户名
- 确保数据库配置文件权限设置正确
- 定期备份数据库
- 生产环境建议限制 `GF-token/add.php` 的访问权限

## 注意事项

1. 视频链接格式：系统会自动去除链接中的域名和协议，只保留路径部分
2. 域名分配：每个用户组可以分配多个域名，用户可以在播放时切换
3. 默认分组：系统会自动创建"注册用户组"，新注册用户默认属于此组
4. 管理员权限：只有用户名为 `admin` 的用户拥有管理员权限
5. 资源下载中心：访问 `GF-token/` 必须为已登录用户，系统会自动从数据库获取邮箱并带参访问

## 常见问题

**Q: 安装时提示数据库连接失败？**
A: 请检查数据库服务是否启动，以及数据库用户名和密码是否正确。

**Q: 视频无法播放？**
A: 请检查：
1. 域名是否正确配置
2. 用户组是否分配了域名
3. 视频链接格式是否正确

**Q: 如何重新安装？**
A: 删除项目根目录下的 `.installed` 文件，然后重新访问 `install.php`。
